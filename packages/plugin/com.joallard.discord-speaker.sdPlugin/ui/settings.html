How to create your Discord app (one time, ~3 min)
  1. Open discord.com/developers/applications → New Application.
  2. Copy the Application ID into Client ID above.
  3. OAuth2 page → Reset Secret → paste into Client Secret (shown once!).
  4. Under OAuth2 → Redirects add exactly http://127.0.0.1 and save.
  5. If an RPC Origins field exists, add http://127.0.0.1 there too.
  6. No bot needed. If one exists: Public Bot OFF.
  7. When Discord pops its authorization dialog, click Authorize (once).

Note: keep the Discord desktop app running, and don't set a custom image on this key in Stream Deck — it would permanently cover the live avatar.
